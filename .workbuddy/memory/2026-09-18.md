### 19:57 落地 P4（行为规范与护栏）✅
- 新增 `harness/guardrails.py`：`Guardrails` dataclass（allowed_tools 白名单 / rules 策略 / validate_args 开关 / secret_patterns 脱敏正则，默认含 sk-/AKIA/Bearer/password/api_key 模式）+ `validate_args(spec, args)` 最小 JSON-schema 校验器（required + 类型 + additionalProperties:false，纯 stdlib）+ `redact_obj` 递归脱敏。

- 核心面试点：span 作为耐久事件与 message 平级→可观测性跨进程存活；OTel 走"可选懒加载 + 中性 span 格式 + 可插拔 exporter"模式，核心零依赖。
